# yazi 設定（Windows / macOS 共用）

yazi は既定の設定をバイナリに内蔵していて、`config/` に置いたファイルは
**その上に重なる**。だからここには「既定から変えたい分だけ」を書く。

対象バージョン: **yazi 26.5.6**（`scoop list yazi` / `brew info yazi` で確認）

| ファイル | 役割 |
|---|---|
| `config/yazi.toml` | 開き方の上書き（Windows は nvim で開く / `O` に Windows Terminal を足す） |
| `config/keymap.toml` | 足したキー（`t` と ブックマーク 6 キー）だけ |
| `config/init.lua` | yamb（ブックマーク）の設定。ドライブ・Scoop・Desktop・この設定ディレクトリを登録 |
| `config/package.toml` | プラグインの固定（`ya pkg upgrade` で更新） |
| `config/bookmark` | ブックマークの実データ。**git 管理外**（起動時に `init.lua` から作り直されるので消してよい） |

`theme.toml` は**置かない**。yazi が端末の明暗に合わせて
`theme-dark` / `theme-light` を自動で選ぶので、片方を固定すると逆に崩れる。

## 操作早見表

迷ったら yazi の中で **`~`**（または `F1`）。全キーの一覧が出て、`f` で絞り込める。
以下は特によく使うものだけ。

### 動く

| キー | 動作 |
|---|---|
| `j` / `k` | 下 / 上 |
| `h` / `l` | 親ディレクトリへ / 中に入る |
| `H` / `L` | 履歴を戻る / 進む |
| `gg` / `G` | 先頭 / 末尾 |
| `<C-d>` / `<C-u>` | 半ページ下 / 上 |
| `gh` | ホーム |
| `g<Space>` | パスを打ってジャンプ（ドライブ移動もこれ。下記） |
| `z` | fzf でファイル/ディレクトリを探してジャンプ |
| `Z` | zoxide で「よく行く場所」へジャンプ |

### ドライブをまたぐ（Windows）

`h`（親へ）は `C:\` で止まる。**ドライブの外には出られない**ので、別の手を使う。

| キー | 動作 |
|---|---|
| `bb` → `C` `D` `E` `Z` | 登録済みドライブへ飛ぶ（**大文字 = ドライブ**） |
| `g<Space>` → `D:\` + `<Enter>` | パスを直接打つ。ここに無いドライブや UNC（`\\server\share`）もこれ |
| `Z` | zoxide。一度行った場所なら名前の一部だけで飛べる |

`g<Space>` の入力欄では補完が効く。`<Tab>` で候補を確定、`<Up>` / `<Down>`
（または `<A-j>` / `<A-k>`）で候補を選ぶ。

このPCのドライブは `C:`（Windows） `D:` `E:` `Z:`（ネットワークの `home`）。
増減したら `config/init.lua` の `drives` を直す（作り直し方はそこのコメント）。

### 選ぶ

| キー | 動作 |
|---|---|
| `<Space>` | 今の行を選択/解除して 1 行下へ |
| `v` | ビジュアルモード（範囲選択） |
| `<C-a>` | 全選択 |
| `<C-r>` | 選択を反転 |
| `<Esc>` | 選択解除 / 検索の取り消し |

### 触る

| キー | 動作 |
|---|---|
| `<Enter>` / `o` | 開く |
| `O` | **開き方を選んで**開く（ここに Windows Terminal がある） |
| `y` / `x` | コピー / 切り取り |
| `p` | 貼り付け（`P` で上書き） |
| `d` | ゴミ箱へ（`D` で完全削除） |
| `a` | 新規作成（末尾を `/` にするとディレクトリ） |
| `r` | 名前を変更 |
| `cc` / `cf` | フルパスをコピー / ファイル名をコピー |
| `.` | 隠しファイルの表示切替 |

### 探す

| キー | 動作 |
|---|---|
| `f` | いまの一覧を**絞り込む**（表示が減る） |
| `/` | いまの一覧内を**検索**（`n` / `N` で次・前） |
| `s` | fd で名前検索（サブディレクトリも） |
| `S` | ripgrep で中身検索 |
| `<C-s>` | 検索を取り消す |

### 並べる・見せ方

| キー | 動作 |
|---|---|
| `,a` / `,m` / `,s` / `,e` | 名前 / 更新日時 / サイズ / 拡張子で並べ替え（大文字で逆順） |
| `ms` / `mm` / `mn` | 行の右端にサイズ / 更新日時 / 何も出さない |
| `<Tab>` | 詳細をその場で表示 |

### タブ・その他

| キー | 動作 |
|---|---|
| `t` | **新しいタブ（この設定で追加。既定は `tt`）** |
| `1`〜`9` / `[` `]` | タブを切り替え |
| `<C-c>` | タブを閉じる（最後の1枚なら終了） |
| `w` | 実行中のタスク一覧 |
| `;` / `:` | シェルコマンドを実行（`:` は終わるまで待つ） |
| `q` | 終了（nvim から開いた場合はその場所が nvim に渡る） |

### ブックマーク（この設定で追加 / yamb プラグイン）

| キー | 動作 |
|---|---|
| `<C-b>` | 今の場所をブックマークに追加 |
| `bb` | 割り当てキーでジャンプ（`config/bookmark` の 3 列目） |
| `B` | fzf で選んでジャンプ |
| `bd` / `bA` | 削除 / 全削除 |
| `br` | 名前を変更 |

登録済み: `C` `D` `E` `Z`（ドライブ） / `p` `P`（Scoop） / `d`（デスクトップ） /
`y`（この設定ディレクトリ）。**キーは重複させない** — 重複すると後から来た方が一覧に出ない。
定義は `config/init.lua`、`<C-b>` で足した分は `config/bookmark`。

`<C-b>` は既定では「1 ページ上へ」。そちらは `<PageUp>` で代替できる。
`t` を 1 打鍵にした副作用で、既定の `tr`（タブ名の変更）は押せない。

## 保守

- **yazi を更新したら**: 起動して TOML エラーが出ないか見る。出たら
  [その版の既定値](https://github.com/sxyazi/yazi/tree/main/yazi-config/preset)
  と見比べて、消えたキー・改名されたキーを直す。
  `config/*.toml` 先頭のコメントにあるタグ URL も上げる。
- **プラグインを更新する**: `ya pkg upgrade`。
  yazi 25.5.31 以降、プラグインの引数は `plugin 名 -- 引数` の形（旧: `plugin 名 引数`）。
- **全文コピーを置かない**。2026-11-03 に、25.x の既定値全文（約1300行）を抱えていたせいで
  26.5.6 が起動できなくなった。実際に変えていたのは 3 ファイル合わせて 3 項目だけだった。
